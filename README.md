# Hanji

Hanji는 마크다운으로 글을 쓰고, 그 글을 책으로 엮어 주는 데스크톱 글쓰기 앱입니다.
짧은 메모부터 긴 원고까지 한 라이브러리에서 관리하고, 쓰는 동안 책이 어떤 모습이 될지 바로 확인한 뒤 PDF·ePub·DOCX로 내보낼 수 있습니다.
Rust와 [gpui](https://www.gpui.rs/)로 만들었으며 macOS와 Windows에서 사용할 수 있습니다.

## 설치

[Releases](https://github.com/drskur-com/hanji/releases/latest) 페이지에서 내려받으세요.

- macOS (Apple Silicon): `Hanji-<버전>-arm64.dmg` — Apple의 서명과 공증을 받았습니다.
- Windows (x64): `Hanji-<버전>-x64.msi`

새 버전이 나오면 앱이 시작할 때 알려 드리고, 원하시면 내려받아 바로 업데이트합니다. 메뉴의 **업데이트 확인…**으로 직접 확인할 수도 있습니다.

## 주요 기능

### 라이브러리

- 모든 글은 직접 고른 폴더에 평범한 마크다운 파일로 저장됩니다. 다른 앱에서 파일을 고쳐도 Hanji가 알아채고 바로 반영합니다.
- 라이브러리는 세 구역으로 나뉩니다. **Inbox**에는 떠오른 생각을 빠르게 적고, **Notes**에는 메모를 최근 순으로 모으고, **Projects**에서는 책을 씁니다. 프로젝트 안에서는 그룹을 여러 단계로 나누고 순서를 직접 정할 수 있습니다.
- 시트를 끌어서 옮기거나, 여러 시트를 하나로 이어 보거나, 라이브러리 전체에서 글을 찾을 수 있습니다.

### 편집기

- 마크다운 기호는 흐리게, 제목은 크게 보여 주고, 문단은 책 스타일에 맞춰 정렬·들여쓰기·간격을 적용합니다.
- 이미지, GIF, 동영상, 오디오, YouTube 영상, 표, 각주, 할 일 목록을 본문 안에 넣고 바로 볼 수 있습니다.
- 이미지 속 글자를 읽어 본문에 넣는 OCR, 기기 안에서 동작하는 받아쓰기와 AI 요약, 특수 문자·이모지 입력도 지원합니다.

### 책 만들기

- 프로젝트 전체나 고른 그룹·시트를 별도 창에서 PDF·ePub 페이지 모양으로 미리 볼 수 있습니다. 글을 고치면 미리보기도 함께 바뀝니다.
- 판형, 부·장·절의 배치와 번호, 쪽 나눔, 표지, 차례, 쪽 번호를 프로젝트마다 설정할 수 있습니다.
- 완성한 원고는 PDF, ePub, DOCX로 내보낼 수 있습니다.

### AI 어시스턴트

- 옆 패널의 어시스턴트가 시트를 읽고 고쳐 줍니다. 다듬기, 교정, 브레인스토밍 같은 스킬을 쓸 수 있고, 고친 부분은 비교해 보고 받아들일지 정할 수 있습니다.
- Amazon Bedrock과 Alibaba Cloud Token Plan을 지원합니다.
- 어시스턴트가 웹 페이지를 읽을 수도 있습니다. 처음 방문하는 사이트는 사용자가 허락해야 읽을 수 있습니다.

### 확장과 테마

- 라이브러리의 `Extensions` 폴더에 Lua(Luau) 스크립트를 넣어 기능을 더할 수 있습니다. 시트 안에 그림이나 애니메이션, 상호작용하는 블록을 그리거나 메뉴 명령을 추가할 수 있으며, 어시스턴트에게 확장을 만들어 달라고 부탁할 수도 있습니다. 확장은 파일과 네트워크에 접근할 수 없는 안전한 환경에서 실행됩니다.
- 기본 테마(Writer, Gruvbox의 라이트·다크) 외에 라이브러리의 `Themes` 폴더에 JSON 테마를 넣어 직접 만든 테마를 쓸 수 있습니다.

## 소스에서 빌드하기

[mise](https://mise.jdx.dev/)로 필요한 도구(Rust, sccache, cmake)를 설치합니다.

```sh
mise install
mise dev      # 개발 모드로 실행
mise check    # 타입 체크
mise bundle   # 설치용 번들 만들기 (macOS .app, Windows .msi)
```

릴리스는 `mise notarize`(macOS 공증) → `mise release`(플랫폼마다 설치 파일을 초안 릴리스에 올리기) → `mise publish`(공개) 순서로 진행합니다.
