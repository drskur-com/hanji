# Hanji

Hanji는 메모 수집부터 원고 구성, 책 미리보기와 내보내기까지 지원하는 마크다운 기반 데스크톱 글쓰기 앱입니다.

떠오른 생각은 메모로 모으고, 긴 원고는 여러 문서로 나누어 작성하세요. 프로젝트에서 원고의 순서와 책 스타일을 정하고, 미리보기로 배치를 확인한 뒤 PDF, ePub, DOCX로 내보낼 수 있습니다.

글은 사용자가 선택한 폴더에 일반 마크다운 파일로 저장됩니다. 다른 편집기에서 수정한 내용도 반영되므로, 익숙한 도구와 함께 사용할 수 있습니다. macOS와 Windows를 지원합니다.

## 설치

[Releases](https://github.com/drskur-com/hanji/releases/latest) 페이지에서 내려받으세요.

- macOS (Apple Silicon): `Hanji-<버전>-arm64.dmg` — Apple의 서명과 공증을 받았습니다.
- Windows (x64): `Hanji-<버전>-x64.msi`

새 버전이 있으면 앱을 시작할 때 알림을 표시합니다. 알림에서 업데이트를 선택하거나, 메뉴의 **업데이트 확인…**으로 직접 확인할 수 있습니다.

## 사용 흐름

1. **라이브러리 선택** — 첫 실행에서 글과 자료를 저장할 폴더를 선택합니다.
2. **메모 수집** — Notes의 기본 그룹인 Inbox에 아이디어를 적고, 주제별 그룹으로 정리합니다. 글 한 편을 담는 개별 문서를 **시트**라고 부릅니다.
3. **원고 구성** — Projects에 프로젝트를 만들고, 원고를 시트와 그룹으로 나누어 작성합니다. 예를 들어 장마다 그룹을 만들고, 그 안에 장면이나 절 단위의 시트를 배치할 수 있습니다.
4. **미리보기와 내보내기** — 책 스타일에서 판형과 제목·본문의 배치를 설정합니다. 미리보기로 표지, 차례, 쪽 나눔을 확인하고 필요한 형식으로 내보냅니다.

## 주요 기능

### 메모와 원고 관리

- **Notes**에서는 메모를 그룹별로 정리하거나, 모든 메모를 최근 순으로 모아 볼 수 있습니다. 메모에 적은 할 일도 한곳에서 확인할 수 있습니다.
- **Projects**에서는 긴 원고를 구성합니다. 그룹을 여러 단계로 나누고 시트의 순서를 정해 책의 구조를 만들 수 있습니다.
- 시트를 끌어서 다른 그룹으로 옮기거나 순서를 바꿀 수 있습니다. 여러 시트를 연결해 미리보기와 내보내기에서 하나의 원고처럼 이어지도록 구성할 수도 있습니다.
- 글은 일반 `.md` 파일로 저장되며, 외부 변경을 감지해 앱에 반영합니다. 라이브러리 전체 검색으로 제목이나 본문에 포함된 내용을 찾을 수 있습니다.

### 읽기 편한 마크다운 편집

- 마크다운 원문을 편집하면서 제목, 강조, 링크 등의 서식을 확인할 수 있습니다. 마크다운 기호는 흐리게 표시하고, 제목은 크기를 달리해 글의 구조가 드러나도록 합니다.
- 프로젝트의 책 스타일에 맞춰 문단 정렬, 첫 줄 들여쓰기, 제목과 문단 사이의 간격을 편집 화면에도 적용합니다.
- 이미지와 GIF를 본문에 표시하고, 표, 각주, 할 일 목록을 삽입할 수 있습니다. 오디오 재생과 동영상·YouTube 카드 삽입도 지원합니다.
- OCR로 이미지 속 텍스트를 인식해 본문에 삽입할 수 있습니다. 특수 문자와 이모지도 삽입 메뉴에서 선택할 수 있습니다.

동영상의 본문 내 재생은 macOS에서 지원합니다. YouTube 영상은 macOS에서는 별도 재생 창으로, Windows에서는 기본 브라우저로 열립니다.

### 책 미리보기와 내보내기

- 프로젝트 전체 또는 선택한 그룹·시트를 별도 창에서 미리 볼 수 있습니다. PDF의 페이지 배치와 ePub의 기기별 읽기 화면을 확인하고, 원고를 수정하면 미리보기도 갱신됩니다.
- 프로젝트마다 판형, 부·장·절의 배치와 번호, 쪽 나눔, 표지, 차례, 쪽 번호를 설정할 수 있습니다.
- **PDF**로 책의 페이지 배치를 담고, **ePub**으로 전자책을 만들거나, **DOCX**로 내보내 Word에서 후속 편집을 할 수 있습니다.

### AI 어시스턴트

오른쪽 패널에서 원고의 교정, 문장 다듬기, 아이디어 구상을 요청할 수 있습니다. 어시스턴트가 시트를 수정하면 변경 전후를 비교하고, 적용할 내용을 선택할 수 있습니다.

- 교정, 다듬기, 브레인스토밍용 스킬을 제공합니다. 스킬은 작업 지침을 담은 파일이며, 라이브러리의 `Skills` 폴더에서 수정하거나 직접 추가할 수 있습니다.
- 웹 페이지를 읽고 글쓰기에 참고할 수 있습니다. 처음 접근하는 사이트는 사용자의 허락을 받은 뒤 읽습니다.
- **설정 → AI**에서 제공자를 연결합니다. **Amazon Bedrock**은 AWS 프로필과 리전을 설정하고, **Alibaba Cloud Token Plan**은 전용 API 키를 입력해 사용합니다.

AI 기능에는 해당 제공자의 계정과 이용 권한이 필요하며, 서비스 이용 조건과 요금 정책이 적용됩니다. 요청에 필요한 원고 내용은 선택한 AI 제공자로 전송됩니다.

### 확장과 꾸미기

- 라이브러리의 `Extensions` 폴더에 Lua(Luau) 스크립트를 넣어 기능을 추가할 수 있습니다. 본문에 그림과 애니메이션, 클릭이나 키 입력에 반응하는 블록을 넣거나 메뉴 명령을 만들 수 있습니다. AI 어시스턴트에게 확장 제작을 요청할 수도 있습니다.
- 확장은 파일 시스템과 네트워크에 직접 접근할 수 없는 제한된 환경에서 실행됩니다.
- Writer와 Gruvbox의 라이트·다크 테마를 제공합니다. 라이브러리의 `Themes` 폴더에 JSON 테마를 추가해 색상을 바꿀 수 있습니다.

## 소스에서 빌드하기

Hanji는 Rust와 [gpui](https://www.gpui.rs/)로 개발합니다. [mise](https://mise.jdx.dev/)로 필요한 도구(Rust, sccache, cmake)를 설치할 수 있습니다.

```sh
mise install
mise dev      # 개발 모드로 실행
mise check    # 타입 체크
mise bundle   # 설치용 번들 만들기 (macOS .app, Windows .msi)
```

<details>
<summary>개발자용 릴리스 절차</summary>

릴리스는 `mise notarize`(macOS 공증) → `mise release`(플랫폼별 설치 파일을 초안 릴리스에 업로드) → `mise publish`(공개) 순서로 진행합니다.

</details>
